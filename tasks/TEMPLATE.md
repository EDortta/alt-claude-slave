# Tarefa: titulo curto

## Objetivo

Uma unica mudanca verificavel.

## Contexto fornecido

- arquivos necessarios;
- contrato ou comportamento existente;
- decisoes ja tomadas pelo planejador.

## Arquivos permitidos

- `src/exemplo.py`
- `tests/test_exemplo.py`

Nao modificar outros arquivos. Parar e reportar se isso for necessario.

## Restricoes

- nao alterar arquitetura;
- nao adicionar dependencias;
- nao acessar rede;
- nao criar commit;
- manter compatibilidade indicada pelo planejador.

## Validacao

```bash
comando-de-lint
comando-de-teste
```

## Criterios de aceite

- comportamento esperado;
- testes novos passam;
- testes existentes continuam passando;
- resposta final lista arquivos alterados e riscos restantes.
